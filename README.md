# TUPLE-AND-RELATED-FUNCTIONS-IN-PYTHON
Aim

   To write a Python program to demonstrate tuple-related functions and operations.
   
Algorithm

1.Start the program.

2.Create a tuple containing the values [10, 20, 30, 20, 40].

3.Display the original tuple.

4.Find and display the length, maximum value, minimum value, and sum of the tuple.

5.Use the count() method to count the occurrences of 20.

6.Use the index() method to find the index of 30.

7.Display the element at index 0.

8.Reverse the tuple using slicing.

9.Display a sliced portion of the tuple.

10.Stop the program.

Source Code
# Program to demonstrate tuple functions

t = (10, 20, 30, 20, 40)

print("Original tuple:", t)

print("Length:", len(t))

print("Maximum value:", max(t))

print("Minimum value:", min(t))

print("Sum:", sum(t))

print("Count of 20:", t.count(20))

print("Index of 30:", t.index(30))

print("Element at index 0:", t[0])

print("Tuple in reverse:", t[::-1])

print("Tuple slicing:", t[1:4])
